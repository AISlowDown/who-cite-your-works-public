# 中文文本报告格式

仅在完成一次引用影响力检索并生成最终文本报告时读取本文件。

## 固定结构

1. `检索口径`：研究者、作者范围、作者总被引门槛、机构范围、自引剔除规则、数据日期。
2. `结果摘要`：被引论文数、符合条件的作者数、引用场景数、取得原文的场景数，以及 Title/Honor 的覆盖情况。执行重点引文深挖时另列“已核验原文的不同作者数 / 目标作者数（默认 10）”、不同引用论文数、是否达标；不足则列缺口、已尝试范围和原因，不以句子数或场景数替代作者数。
3. `作者概览`：每位作者一行，按作者总被引降序排列；列出作者、机构、角色、总被引、Title、Honor、引用场景数。
4. `全部引用场景`：一个引用关系一行，同一作者的多篇引用不得合并；列出作者、机构、角色、总被引、Title、Honor、引用论文、被引论文、引用原句、中文总结。

配套 Excel 默认使用 [双索引输出规范](report-indexes.md)：引用作者索引一位作者一行，本人论文索引一篇本人论文一行。文本中的逐条场景与 JSON 明细继续完整保留；索引聚合不改变引用关系或场景计数。可增加本人论文概览，但不得以概览替代逐条引用原文。

## 展示规则

- 使用中文 Markdown；论文英文题名和引用原句保持原文。
- 多机构、多角色、多职称或多项荣誉使用 ` • ` 分隔。
- Markdown 表格中的换行统一转为 `<br>`，竖线转义为 `\|`。
- 不截短引用原句，不把缺失信息补写成确定结论。
- 默认剔除作者自引，并在结果摘要中列出被剔除的引用论文或引用场景数量。
- 无引用上下文时写“引用关系已确认，但引用原因暂不可判定”，并区分本轮未深挖、已尝试未取得、检索未完成；不能未查全文就断言原文未公开。
- 不展示来源编码、证据编码、内部 coding、身份冲突或人工审核流程；这些信息留在 JSON 证据数据中。
- 报告末尾注明：引用次数、职称、荣誉和机构排名会随时间变化，本报告对应其生成日期。
